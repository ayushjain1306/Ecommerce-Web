# Project Title

E-Commerce Website

## 🚀 Demo

[Live Demo](https://ecommerce-web-puce.vercel.app) | [Github Repo](https://github.com/ayushjain1306/Ecommerce-Web.git)

## 📌 Features

- Product Listings with search and filters
- Paypal Payment Gateway Integration
- Admin Panel (add, edit and delete products) and manage orders
- Add/Remove from cart
- Product Reviews & Ratings
- User Authentication (Login/Signup)

## 🛠️ Tech Stack

**Client:** React, Axios, Material-UI, Bootstrap etc.
**Server:** Node.js, Express, Multer etc.
**Database:** MongoDB, Firebase
**Other:** JWT, Paypal etc.

## ⚙️ Installation

1. Clone the repo

https://github.com/ayushjain1306/Ecommerce-Web.git

2. Navigate to Folder

cd Ecommerce-Web/frontend (for frontend)
cd Ecommerce-Web/backend (for backend)

3. Install Dependencies

npm install (for both frontend and backend)

4. Start the Project

npm run dev (for frontend)
npm start (for backend)

5. Set Environment Variables
Create .env file in root directory of backend and add following variables:-

URL="your-mongodb-url"
FIREBASE_SECRET_KEY="your-firebase-secret-key"
SECRET_KEY="your-jwt-secret-key"
ADMIN_SECRET_KEY="your-jwt-secret-key-for-admin"
